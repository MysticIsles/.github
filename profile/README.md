# ✨ MysticIsles 

MysticIsles has always been a passion project from the very beginning. After the downfall of my favourite server at the time (Mineclub), I realised that the community was left in limbo; There was nowhere to go. Through the disarray, I created MysticIsles with the goal of building a platform to hold up the community and give them a space to continue thriving. 

However, that vision never came to life. Disorganised code and countless hours were poured into the project, but ultimately, there was nothing to show for it. I had become too busy with real life to give the server the time and care it truly deserved. 

Flash forward to today, I finally have time and energy to return to a once-loved project. It's time for this server to soar and become what it was always meant to be
